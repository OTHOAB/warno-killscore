# warno-killscore
a bunch of scripts to create overlay video from basic csv

killfeedscript.py creates adjusted feed with recent kills

createoverlay.py creates overlay.mov of cumsum kills for both sides, including recent kills

feed.csv and feed_adjusted.csv are examples

killfeed1.xls is how i manually parsed data from screenshots

overlay.mov to be added to your video as a layer in video editor of your choice
